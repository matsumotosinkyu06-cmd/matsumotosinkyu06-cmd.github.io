# まつもと美容鍼灸整体サロン ホームページ

`site/index.html` が本体です。ブラウザで開くとそのまま表示されます。
公開時は `site/` フォルダの中身（`index.html` と `assets/`）をまるごとサーバーにアップロードしてください。

## 構成（上から順に）

1. ヒーロー（顔だけじゃなく身体からきれいに／初回体験2,000円〜）

5. 美容鍼／整体のイメージ帯（メニューの直前に写真2枚）
6. メニュー・料金（美容鍼3プラン＋整体2メニュー。※料金表画像は掲載しない指示のためテキスト＋表で作成）
6. ご来院から施術までの流れ（6ステップ）※頂いた画像の文章を反映
7. お客様の声（20代・30代・40代の3件）※頂いた画像の文章を反映
8. 院長紹介（松本翔太／はり師・きゅう師／施術歴10年以上）
9. よくある質問
10. アクセス・営業時間・地図
11. 当院までの道順（JR堺市駅から4ステップ＋順路写真2枚）※頂いた画像を使用
12. 予約CTA／フッター
